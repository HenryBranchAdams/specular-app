# Automatic block classification

Type: enhancement
Status: resolved

## Current behavior

Every writing block exposes a kind selector. The selected kind affects Connections filtering and presentation, reference fields, snapshots, and exports, which makes an organizational concern feel like a required writing decision.

## Desired behavior

Remove the kind selector from the writing surface. After automatic-organization consent, substantive blocks are classified during a debounced organization pass. A substantive block contains at least eight words. Classification remains quiet metadata used for organization and Connections.

The author can inspect and correct a generated kind from Connections. A correction makes that block author-managed and prevents later automatic responses from replacing it. Classification responses are version-aware and cannot apply to content that changed after the request began.

Reference semantics must be separated from inferred kind. A quiet explicit source-attachment action controls reference metadata, quotation treatment, and export behavior. Automatic classification alone never reveals source fields or turns authored prose into a quotation.

## Key interfaces

- Block-kind provenance: generated or author-managed.
- Automatic organization request and stale-response guard.
- Connections filters and correction control.
- Explicit source attachment, snapshots, and exports.
- Workspace migration and persistence.

## Acceptance criteria

- No block-kind selector is visible in the writing document.
- Eligible blocks receive generated kinds after consent without blocking typing.
- Connections can filter by generated kinds and offers a low-noise correction control.
- A corrected kind survives reload and cannot be overwritten by a delayed or later automatic response.
- A response generated for older block content is discarded.
- Inferred reference classification alone does not show source fields or alter snapshot, Markdown, or published-page quotation treatment.
- Explicitly attached source metadata remains editable and exports with provenance.
- Existing kinds and references migrate without data loss.

## Out of scope

- Removing block kinds from Connections or the domain model.
- Inferring source citations or inventing reference metadata.
- Showing confidence scores or classification telemetry in the document.

## Comments

## Answer

Removed kind selection from the writing surface, added consent-gated version-aware classification, and made Connections the quiet correction surface. Source attachment now independently controls reference fields, quotation treatment, and export behavior.
