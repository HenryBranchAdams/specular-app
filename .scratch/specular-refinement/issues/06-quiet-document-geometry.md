# Quiet document geometry and controls

Type: enhancement
Status: resolved

## Current behavior

The header wordmark is aligned to the viewport padding rather than the document page, writing text is visually oversized, and the New block action occupies more visual weight than its frequency warrants.

## Desired behavior

At desktop widths, align the Specular wordmark with the left edge of the document page. Reduce canonical writing typography to a calmer reading size while preserving generous line height and the page's editorial character. Replace the labeled New block pill with a plus-only control whose tooltip, accessible name, and focus treatment make the action unambiguous.

Responsive layouts must retain comfortable page padding and avoid horizontal overflow. The icon-only action must remain easy to discover and operate by pointer, touch, and keyboard.

## Key interfaces

- Shared header and workspace-grid geometry.
- Document page padding and responsive breakpoints.
- Canonical-writing typography.
- Add-block action and tooltip.

## Acceptance criteria

- At the primary desktop viewport, the wordmark and document page share the same left alignment within one pixel.
- Canonical writing computes to no more than eighteen pixels at desktop and remains at least sixteen pixels on narrow screens.
- Line height remains at least 1.55 and long writing remains readable without clipping.
- New block renders as a plus-only control with an accessible name and tooltip.
- The control has a minimum forty-four-pixel interactive target and visible keyboard focus.
- Desktop, tablet, 430-pixel, 375-pixel, and 320-pixel layouts have no horizontal overflow.
- Delete, microphone, history, and reference controls remain operable after the typography and alignment changes.

## Out of scope

- Replacing the page-based visual language.
- Changing the document title scale unless needed to prevent overflow.
- Redesigning the global navigation.

## Comments

## Answer

Aligned the wordmark to the page, reduced canonical writing size, added resilient auto-sizing for title and writing fields, and converted New block and Delete to quiet icon controls with labels, tooltips, focus rings, and touch-sized targets.
