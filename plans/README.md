## Grounded direction options

1. **Prove the live questioning loop before expanding surfaces.** The repo explicitly leaves live qualitative review pending. Run a billable, blinded multi-turn review only with explicit authorization, then use it as the gate before public MCP or voice rollout.
2. **Complete local-first restore.** The parser and transactional import already exist, but the product exposes only Export. Add a local parse-before-write restore flow with automatic pre-import backup and destructive confirmation.
3. **Make unfinished lines quietly resumable.** Supported capsule actions can create multiple active threads while startup restores only the newest. A restrained `Unfinished` section inside Capsules fits the one-column ethos better than a dashboard.
4. **Lead with the private PWA.** It is the only surface with the full durable local loop. Keep MCP contract-compatible and voice flagged until the text loop and its operator gates have live evidence.
