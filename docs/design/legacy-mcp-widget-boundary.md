# Legacy MCP widget boundary

The [README compatibility statement](../../README.md#legacy-mcp-compatibility) identifies the earlier native/MCP server and `public/specular-widget.html` as a separately built compatibility surface. It is not an active hosted-product UI surface and is intentionally excluded from the hosted [UI surface manifest](./ui-surface-manifest.json).

This boundary is classification only. The current UI quality work does not change the widget source, transport, artifacts, or compatibility tests. Any decision to retain, adapt, or remove that surface requires separately scoped future work and qualification.
